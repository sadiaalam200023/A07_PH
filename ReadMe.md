Project Name -

বাজার দর / BazarDor

Short Description -

বাজার দর is a Bangla-language web application that helps users explore daily market prices of essential commodities in Bangladesh. Users can view prices of rice, lentils, oil, vegetables, fish, meat, eggs, dairy products, and spices, along with price changes and category-based product information.

Technologies Used

Next.js – React framework for building the web application

React – Component-based user interface

TypeScript – Type-safe JavaScript development

Tailwind CSS – Responsive styling and layout

REST API – Fetching product prices and category data

Better Auth – User authentication

Daisy Ui - For ui component templates

Vercel - for deploymeny

Five Key Features -

Daily Market Prices: View the latest available prices of essential household commodities.

Category-Based Browsing: Browse products by categories such as চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ, and মসলা.

Price Change Indicators: See whether product prices have increased or decreased, with percentage changes.

Responsive Design: Access the application on mobile phones, tablets, and desktop computers.

User Authentication: Sign up, sign in, and access a personalized profile
